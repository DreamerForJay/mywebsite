# mywebsite

楊杰倫 Chieh-Lun Yang 的個人網站。

**線上網址：** https://dreamerforjay.github.io/mywebsite/

## 內容

單一 HTML 檔案（`index.html`），CSS 與 JavaScript 全部內嵌，沒有建置流程。直接編輯、推上去就會更新。

- 深色／亮色主題切換，預設跟隨系統設定
- 響應式：375 / 768 / 1440 皆已驗證
- 內嵌 Perxona AI 分身（`<sv-agent>`），API key 綁定 `dreamerforjay.github.io` 網域

## 本機預覽

用瀏覽器直接開 `index.html` 即可。注意 AI 分身元件因為網域綁定，只有在 GitHub Pages 上才會載入。

## 部署

推到 `main` 分支後，在 repo 的 Settings → Pages 把 Source 設為 `main` / `root`。
